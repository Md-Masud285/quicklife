# 🚀 QuickLife - অল-ইন-ওয়ান স্মার্ট মোবাইল অ্যাপ্লিকেশন

**QuickLife** হলো একটি আধুনিক, দ্রুতগতির এবং মাল্টি-ফিচার মোবাইল অ্যাপ যা ব্যবহারকারীদের দৈনন্দিন জীবনকে করে তোলে সহজ, স্বাস্থ্যকর ও সুরক্ষিত।

---

## 🌟 প্রধান মডিউল ও ফিচারসমূহ:

### ১. 🩸 রক্তদাতা হাব ও জরুরি সেবা (Blood Finder & Emergency Hub)
- **স্মার্ট সার্চ:** থানা (Thana/Upazila) $\rightarrow$ জেলা (District) $\rightarrow$ রক্তের গ্রুপ অনুযায়ী দ্রুত ফিল্টারিং।
- **স্বয়ংক্রিয় এভেইলেবিলিটি ট্র্যাকার:** শেষ রক্তদানের তারিখ অনুযায়ী ৯০ দিন পূর্ণ হলে "রক্তদানে প্রস্তুত", অন্যথায় "সম্প্রতি রক্তদান করেছেন" স্ট্যাটাস প্রদর্শন।
- **যোগাযোগের সুবিধা:** সরাসরি ১-ট্যাপ ফোন কল বাটন এবং সোশ্যাল মিডিয়া (Facebook / WhatsApp / Email) আইকন লিংক।
- **১ জন ডোনার ১ প্রোফাইল নীতি:** ডুপ্লিকেট এন্ট্রি প্রতিরোধ এবং যেকোনো সময় নিজের প্রোফাইল এডিট/ডিলিটের ব্যবস্থা।

### ২. 💊 স্বাস্থ্য ও ওষুধের অ্যালার্ম (Medicine Tracker & Custom Alarm)
- ওষুধের নাম, ডোজ এবং খাওয়ার সময় (খাওয়ার আগে/পরে/সাথে) অনুযায়ী কাস্টম অ্যালার্ম।
- **সাউন্ড অপশন:** অ্যাপের নিজস্ব ডিফল্ট শান্ত সুর অথবা ব্যবহারকারীর নিজস্ব ডিভাইস থেকে যেকোনো অডিও/MP3/MP4 ফাইল আপলোড ও লাইভ টেস্ট সুবিধা।
- **ব্যক্তিগত জরুরি নম্বর সেভার:** ব্যবহারকারীর নিজ থানার ওসি, নিকটস্থ অ্যাম্বুলেন্স ও ফায়ার সার্ভিসের নম্বর সেভ ও ১-ট্যাপ কল সুবিধা।

### ৩. 📚 স্টুডেন্ট সূত্র সম্ভার (Study Assistant & Formula Book)
- বিষয়ভিত্তিক তালিকা: **গণিত (Math)**, **পদার্থবিজ্ঞান (Physics)**, এবং **রসায়ন (Chemistry)**।
- প্রতিটি সূত্রের সুন্দর কার্ড ভিউ, ব্যাখ্যা এবং **One-Tap Copy Button**।

### ৪. ✨ AI দরখাস্ত মেকার ও ইউনিভার্সাল ট্রান্সলেটর (AI Tools & Multi-Language Translator)
- **সিভি ও দরখাস্ত মেকার:** চাকরি, স্কুল বা অফিসের ছুটির আবেদনপত্র স্বয়ংক্রিয়ভাবে তৈরি, কপি এবং **PDF ডাউনলোড**।
- **স্মার্ট অনুবাদক:** বাংলা, ইংরেজি, আরবি, হিন্দি সহ বিশ্বের সব প্রধান ভাষার মধ্যে দ্রুত অনুবাদ, অডিও উচ্চারণ ও ওয়ান-ট্যাপ কপি সুবিধা।

### ৫. 📢 ভবিষ্যতের গুগল অ্যাড (AdMob Ready)
- ব্যানার অ্যাড এবং স্পন্সরশিপের জন্য প্রি-বিল্ট স্লট ও প্লেসমেন্ট ডিজাইন।

## 💻 যেভাবে চালাবেন (How to Run):

```bash
# প্রজেক্ট ডিরেক্টরিতে যান
cd quicklife

# ডিপেন্ডেন্সি ইনস্টল করুন (যদি না করা থাকে)
npm install

# ডেভেলপমেন্ট সার্ভার চালু করুন (লাইভ প্রিভিউ)
npm run dev

# প্রোডাকশন বিল্ড তৈরি করুন
npm run build
```
